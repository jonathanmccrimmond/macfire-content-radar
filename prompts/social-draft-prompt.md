# MacFire Social Draft Prompt

Use only the supplied source links and notes.

## Task

Draft one Facebook post, one X post, and one LinkedIn post for MacFire.

## Rules

- Use only public, verifiable facts from the sources.
- Keep the tone practical, calm, and useful.
- Do not invent dates, regulations, or legal interpretations.
- Do not mention confidential client or lead data.
- Avoid legal advice language.
- When you include source links or source references, keep the visible link text in quotation marks.
- Keep the Facebook version shorter and slightly more conversational.
- Keep the X version concise enough for a single post, ideally under 280 characters, with no thread.
- Add 1 to 2 relevant hashtags to the X draft.
- Add 3 to 5 relevant hashtags at the end of the LinkedIn draft.

## Output Format

Return Markdown with:

1. Title
2. One-sentence angle
3. Facebook draft
4. X draft
5. LinkedIn draft
6. Source list
7. Short review note
